# Smart Resume Builder

A responsive web application that helps students and job seekers create professional resumes easily.

## About the Project

Smart Resume Builder allows users to enter their personal details, educational qualifications, skills, projects, certifications and experience. It automatically displays a resume preview and allows users to save it as a PDF.

## Features

- Personal information entry
- Career objective section
- Education details
- Technical and soft skills
- Project details
- Certifications
- Internship and experience details
- Live resume preview
- Download resume as PDF
- Save draft in browser
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Browser Print to PDF

## How to Run

1. Download or clone this repository.
2. Extract the project folder.
3. Open `index.html` in your browser.
4. Enter your resume information.
5. View your resume in the live preview.
6. Click Download as PDF.
7. Choose Save as PDF in the print dialog.

## How to Deploy

This project can be hosted using GitHub Pages.

1. Open the GitHub repository.
2. Go to Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click Save.
